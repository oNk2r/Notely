# Notely

Notely is a lightweight note-taking application with a separated backend (Express + MongoDB) and frontend (React + Vite + Tailwind). It includes rate limiting via Upstash, a simple notes API, and a modern React UI.

**Repository structure**

- `backend/` — Express API, MongoDB models, Upstash rate limiter.
- `frontend/` — React (Vite) single-page app, Tailwind CSS, Axios client.

**Key features**

- Create, read, update, delete notes
- Simple REST API with rate limiting
- Responsive React UI

**Tech stack**

- Backend: Node.js, Express, Mongoose (MongoDB), Upstash (rate limiting & Redis client)
- Frontend: React, Vite, Tailwind CSS
